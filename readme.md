## Project Description

This is a DMS application for managing personal / portfolio projects.
Its primary purpose is to serve as the starter repo for CEN4802 lessons and assignments.

## Running the Application

```bash
  # start backend on localhost:8080
  cd backend
  mvn spring-boot:run
```

Then, in a new terminal session

```bash
  # start frontend on localhost:3000
  cd frontend
  npm install
  npm run dev
```
